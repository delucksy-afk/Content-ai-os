# Thumbnail Quality Standard

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Quality Dimensions

- Clarity
- Visual Hierarchy
- Legibility
- Audience Fit
- Promise Alignment
- Title Complementarity
- Truthfulness
- Simplicity
- Production Feasibility
- Testability

## Quality Levels

### Draft
Concept ยังไม่ผ่าน Review

### Reviewed
ผ่านการตรวจ Concept และ Truthfulness

### Production Ready
ผ่าน Quality Gate และพร้อมผลิต

### Deprecated
ไม่ควรใช้เป็น Concept ปัจจุบัน

## Gate

```text
[ ] Primary idea clear
[ ] Visual hierarchy clear
[ ] Legible at small size
[ ] Audience fit
[ ] Promise aligned
[ ] Title relationship checked
[ ] No misleading visual
[ ] Production feasible
[ ] Review passed
```
