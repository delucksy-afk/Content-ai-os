# 07 Thumbnail

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1  
**อ้างอิง:** `01 Constitution/`, `03 Knowledge/`, `04 Prompt/`, `05 Workflow/`, `06 Script/`

## Purpose

Thumbnail คือส่วนหนึ่งของ Content Packaging System ที่ทำงานร่วมกับ Title และ Content Promise เพื่อช่วยให้ผู้ชมเข้าใจหัวข้อและตัดสินใจว่าจะสนใจต่อหรือไม่ โดยต้องไม่ทำให้เกิดความคาดหวังที่เนื้อหาส่งมอบไม่ได้

## Core Flow

```text
Script Handoff
 ↓
Audience / Intent
 ↓
Core Promise
 ↓
Visual Angle
 ↓
Composition
 ↓
Text / No-text Decision
 ↓
Title ↔ Thumbnail Check
 ↓
Misleading Check
 ↓
Thumbnail Brief
 ↓
Review / Revision
 ↓
Packaging Package
```

## Principles

- Thumbnail ต้องสอดคล้องกับ Content Promise
- Title และ Thumbnail ควรเสริมกัน ไม่จำเป็นต้องพูดซ้ำกัน
- ความชัดเจนมาก่อนความซับซ้อน
- ไม่ใช้ Visual ที่ทำให้เข้าใจผิด
- ไม่ถือว่า CTR มีสูตรเดียวหรือรับประกันได้
- ต้องออกแบบให้เหมาะกับ Context, Audience และ Platform
- Thumbnail สำคัญต้องมี Version และ Review
