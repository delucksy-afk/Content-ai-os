## Review Triggers

- Script / Promise เปลี่ยน
- Title เปลี่ยนอย่างมีนัยสำคัญ
- Audience / Strategy เปลี่ยน
- พบ Misleading Issue
- Performance data ชี้ว่าควรทดสอบแนวทางใหม่
- Platform placement เปลี่ยน

Performance data ใช้เพื่อเรียนรู้และทดสอบ ไม่ใช้เป็นหลักฐานว่ามีสูตรสากลที่รับประกันผล
