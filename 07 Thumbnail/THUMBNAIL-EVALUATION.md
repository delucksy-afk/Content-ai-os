# Thumbnail Evaluation

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Evaluation Dimensions

- First-glance clarity
- Visual hierarchy
- Title complementarity
- Promise alignment
- Audience fit
- Legibility
- Misleading risk
- Production feasibility

## Review Types

### Concept Review
ตรวจว่า Concept สื่อสารอะไรและสอดคล้องกับ Promise หรือไม่

### Small-size Review
ตรวจการอ่านในขนาดเล็กและการรับรู้จุดสนใจหลัก

### Pair Review
ดู Title + Thumbnail เป็นชุด ไม่ดูแยกกัน

### Truthfulness Review
ตรวจว่าภาพไม่ทำให้ผู้ชมเข้าใจผิดเกี่ยวกับ Content

### Performance Review
เมื่อมีข้อมูลจริง ให้เปรียบเทียบตามบริบทของ Traffic Source / Audience / Content และไม่สรุปเหตุผลเกินข้อมูล
