# Knowledge Quality Standard

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Quality Dimensions

ทุก Knowledge Entry สำคัญควรประเมิน:

- Accuracy — ถูกต้องตาม Evidence
- Traceability — ย้อนกลับ Source ได้
- Context — ไม่ถูกตัดบริบทจนผิดความหมาย
- Reusability — นำไปใช้ซ้ำได้
- Clarity — เข้าใจได้โดยไม่ต้องอ่าน Research ทั้งหมด
- Freshness — มีการจัดการอายุข้อมูล
- Uncertainty — ระบุข้อจำกัดและความไม่แน่นอน
- Consistency — ไม่ขัดกับ Knowledge ที่ยืนยันแล้วโดยไม่มีเหตุผล

## Quality Levels

### Verified
Evidence แข็งแรงและผ่าน Quality Gate

### Supported
มี Evidence เหมาะสมแต่มีข้อจำกัด

### Conditional
ใช้ได้ภายใต้เงื่อนไขที่ระบุ

### Deprecated
ไม่ควรใช้เป็นข้อมูลปัจจุบันอีกต่อไป

### Unverified
ยังไม่ควรนำไปใช้เป็น Knowledge ที่เชื่อถือได้

## Quality Gate

```text
[ ] Source valid
[ ] Evidence adequate
[ ] Claim scoped
[ ] Context preserved
[ ] Uncertainty stated
[ ] Traceability available
[ ] Reuse value exists
[ ] Freshness reviewed
```
