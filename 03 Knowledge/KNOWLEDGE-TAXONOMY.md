# Knowledge Taxonomy

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Primary Types

- Fact — ข้อเท็จจริงที่มี Evidence รองรับ
- Concept — แนวคิดหรือหลักการ
- Method — วิธีการหรือกระบวนการ
- Pattern — รูปแบบที่สังเกตได้จาก Evidence หลายส่วน
- Insight — ความเข้าใจที่สังเคราะห์ขึ้น
- Rule — กฎที่ระบบกำหนดให้ใช้
- Decision — การตัดสินใจที่มีเหตุผลและบริบท
- Reference — ข้อมูลสำหรับอ้างอิง

## Required Metadata

ทุก Entry ควรมี:

- Knowledge ID
- Title
- Type
- Domain
- Tags
- Status
- Summary
- Source / Research ID
- Confidence
- Created Date
- Updated Date
- Review Trigger

## Naming

ชื่อควร:

- สั้นและสื่อความหมาย
- ใช้คำที่ค้นหาได้
- ไม่ใช้ชื่อที่คลุมเครือ
- ไม่ใส่ข้อสรุปเกิน Evidence ลงในชื่อ

## Tags

Tags ใช้สำหรับการค้นหาและเชื่อมโยง ไม่ควรใช้แทน Taxonomy หลัก
