# Script Quality Standard

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Quality Dimensions

- Accuracy — Claims ไม่เกิน Evidence
- Relevance — เนื้อหาตรง Audience และ Objective
- Clarity — เข้าใจง่ายและไม่กำกวม
- Structure — ลำดับเนื้อหามีเหตุผล
- Promise Alignment — Hook / Title / Content สอดคล้อง
- Value Density — แต่ละส่วนมีคุณค่า
- Flow — การเปลี่ยนช่วงไม่สะดุดโดยไม่จำเป็น
- Originality — ไม่เลียนแบบโดยไม่จำเป็น
- Production Readiness — สามารถนำไปผลิตต่อได้
- Policy / Ethics — สอดคล้องกับ Constitution

## Quality Levels

### Draft
ยังไม่ผ่าน Review

### Reviewed
ผ่านการตรวจโครงสร้างและ Claim

### Production Ready
ผ่าน Quality Gate และพร้อมส่งต่อ

### Deprecated
ไม่ควรใช้เป็น Script ปัจจุบัน

## Gate

```text
[ ] Audience clear
[ ] Objective clear
[ ] Promise aligned
[ ] Structure sound
[ ] Important claims supported
[ ] No fabricated facts
[ ] Hook truthful
[ ] Ending / CTA appropriate
[ ] Production notes usable
[ ] Final review passed
```
