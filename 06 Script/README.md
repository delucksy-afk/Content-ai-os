# 06 Script

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1  
**อ้างอิง:** `01 Constitution/`, `02 Research/`, `03 Knowledge/`, `04 Prompt/`, `05 Workflow/`

## Purpose

Script คือ Production Layer สำหรับเปลี่ยน Content Brief + Evidence + Knowledge + Workflow ให้เป็นสคริปต์ที่มีโครงสร้าง มีเหตุผล ตรวจสอบได้ และพร้อมเข้าสู่การผลิตจริง

Script ไม่ใช่พื้นที่สำหรับแต่งข้อความอย่างเดียว แต่เป็นผลลัพธ์ที่ต้องรักษาความถูกต้องของ Claim, ความเหมาะสมกับ Audience และเป้าหมายของ Content

## Core Flow

```text
Brief
 ↓
Research / Knowledge
 ↓
Script Strategy
 ↓
Structure
 ↓
Hook
 ↓
Narrative / Body
 ↓
Evidence / Claims
 ↓
CTA / Ending
 ↓
Quality Check
 ↓
Revision
 ↓
Script Package
```

## Script Package

ควรประกอบด้วย:

- Brief
- Audience
- Objective
- Key Message
- Structure
- Script
- Source / Evidence references when claims require them
- Visual / Production notes when needed
- Quality report
- Version

## Principles

- เขียนตาม Brief และ Audience ไม่ใช่ตามความชอบของผู้เขียนเพียงอย่างเดียว
- Claim สำคัญต้องไม่เกิน Evidence
- Hook ต้องสอดคล้องกับ Promise
- Script ต้องส่งมอบ Value ตามที่สัญญาไว้
- หลีกเลี่ยงการสร้างข้อเท็จจริงขึ้นเอง
- เมื่อข้อมูลไม่พอให้ระบุ Missing Information
- Script ที่สำคัญต้องผ่าน Quality Gate ก่อน Handoff
