# Script Structure

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

โครงสร้างพื้นฐานสำหรับ Long-form YouTube Script:

```text
1. Hook
2. Context / Setup
3. Core Promise
4. Main Sections
5. Evidence / Examples
6. Pattern / Insight / Explanation
7. Payoff
8. CTA / Next Step
9. Ending
```

## Hook

หน้าที่คือทำให้ผู้ชมเข้าใจว่าเหตุใดควรสนใจต่อ โดยไม่สร้าง Promise ที่เนื้อหาส่งมอบไม่ได้

## Context

ให้ข้อมูลขั้นต่ำที่จำเป็นต่อการเข้าใจเรื่อง

## Core Sections

แต่ละ Section ควรตอบคำถามหรือส่ง Value ที่ต่อเนื่องกัน และลดการวนซ้ำ

## Evidence / Examples

ใช้เมื่อช่วยเพิ่มความเข้าใจหรือรองรับ Claim สำคัญ

## Payoff

ส่งมอบ Insight หรือผลลัพธ์ที่สอดคล้องกับ Promise

## CTA

ควรสัมพันธ์กับเป้าหมายของ Content และไม่รบกวน Value หลัก

## Adaptation

โครงสร้างนี้เป็น Default ไม่ใช่สูตรตายตัว ต้องปรับตาม Format, Audience และ Topic
