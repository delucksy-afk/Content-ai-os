# Script Lifecycle

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

```text
Brief
 ↓
Draft
 ↓
Review
 ↓
Revision
 ↓
Production Ready
 ↓
Published
 ↓
Performance Review
 ├── Update
 └── Archive
```

## Review Triggers

- Brief เปลี่ยน
- Evidence สำคัญเปลี่ยน
- พบ Factual Error
- Audience / Strategy เปลี่ยน
- Content Performance แสดงปัญหาที่เกี่ยวกับ Script
- Platform requirement เปลี่ยน

## Version Rule

การแก้ Claim, Structure, Hook, Promise หรือ CTA ที่มีนัยสำคัญควรสร้าง Version ใหม่หรือบันทึก Change อย่างชัดเจน
