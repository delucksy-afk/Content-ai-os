# Script Architecture

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Layers

```text
L1 Brief
L2 Audience
L3 Objective / Promise
L4 Knowledge / Evidence
L5 Angle / Key Message
L6 Structure
L7 Narrative
L8 Production Notes
L9 Quality / Verification
L10 Handoff
```

## Separation of Concerns

- Brief บอกโจทย์
- Audience บอกผู้รับสาร
- Objective บอกผลลัพธ์ที่ต้องการ
- Knowledge / Evidence บอกสิ่งที่เรารู้และอ้างอิงได้
- Angle กำหนดมุมเล่า
- Structure กำหนดลำดับ
- Narrative คือข้อความที่ผู้ชมได้รับ
- Production Notes ช่วยการถ่ายทำ/ตัดต่อเมื่อจำเป็น
- Quality ตรวจความถูกต้องและความสอดคล้อง

## Script vs Prompt

Prompt บอก AI ว่าต้องทำอะไร

Script คือ Output / Production Artifact ที่ผ่าน Workflow และ Quality Gate

## Script vs Knowledge

Knowledge เป็นความรู้ที่นำกลับมาใช้ซ้ำ

Script เป็นงานเฉพาะชิ้นและไม่ควรถูกนำไปเป็น Fact ถาวรโดยอัตโนมัติ
