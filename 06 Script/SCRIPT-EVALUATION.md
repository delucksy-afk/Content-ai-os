# Script Evaluation

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Evaluation Dimensions

- Brief adherence
- Audience fit
- Promise alignment
- Factual accuracy
- Evidence coverage
- Narrative clarity
- Structure / pacing
- Value delivery
- CTA relevance
- Production readiness

## Test Types

### Structural Test
ตรวจว่ามีส่วนประกอบครบตาม Script Specification

### Claim Test
ตรวจ Claim สำคัญกลับไปยัง Evidence / Source

### Read-through Test
อ่านต่อเนื่องเพื่อตรวจ Flow และความเข้าใจ

### Audience Test
ประเมินว่าผู้รับสารเป้าหมายเข้าใจและได้รับ Value ตามโจทย์หรือไม่

### Production Test
ตรวจว่าข้อความสามารถนำไปผลิตจริงได้

## Release Gate

```text
[ ] Structure passes
[ ] Critical claims verified
[ ] Promise alignment passes
[ ] Audience fit passes
[ ] No unresolved critical issues
[ ] Production notes complete where needed
[ ] Version recorded
```
