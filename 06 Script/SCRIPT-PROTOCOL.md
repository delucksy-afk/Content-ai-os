# Script Protocol

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Standard Flow

```text
Brief Validation
 ↓
Audience / Objective
 ↓
Knowledge & Evidence Selection
 ↓
Angle / Key Message
 ↓
Structure
 ↓
Hook
 ↓
Body / Narrative
 ↓
Proof / Examples
 ↓
CTA / Ending
 ↓
Quality Review
 ↓
Revision
 ↓
Handoff
```

## Required Inputs

- Topic
- Audience
- Content objective
- Promise / angle
- Format / platform
- Desired length or runtime when relevant
- Evidence / Knowledge dependencies

## Missing Input Rule

ถ้าข้อมูลสำคัญไม่พอ ห้ามเดาเป็น Fact ให้:

1. ระบุข้อมูลที่ขาด
2. ระบุ Assumption ถ้าจำเป็นต้องทำงานต่อ
3. ทำเครื่องหมายส่วนที่ต้องตรวจ

## Claim Rule

แยกให้ชัดระหว่าง:

- Fact
- Interpretation
- Example
- Opinion
- Recommendation

## Completion Gate

```text
[ ] Brief validated
[ ] Audience defined
[ ] Objective defined
[ ] Promise defined
[ ] Structure complete
[ ] Hook aligned
[ ] Claims supported
[ ] CTA appropriate
[ ] Quality review passed
[ ] Version recorded
```
