# Review Cycle

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Review Levels

### Per Run
ตรวจ Output และ Quality Gate

### Weekly / Periodic
ตรวจ Error, Rework, Cost, recurring issues และ pending changes

### Monthly / Strategic
ตรวจ Architecture, Dependencies, Knowledge freshness, Metrics และ Roadmap

## Review Output

ทุก Review ที่มีการตัดสินใจควรลงบันทึก:

- Finding
- Evidence
- Decision
- Owner
- Due date when applicable

## Triggered Review

ไม่ต้องรอรอบเวลาเมื่อเกิด:

- Critical incident
- Major dependency change
- Constitution change
- Repeated quality failure
- Unexpected performance / cost change
