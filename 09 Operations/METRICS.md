# Operations Metrics

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Metric Groups

### Reliability

- Success rate
- Failure rate
- Retry rate
- Recovery time

### Quality

- Quality pass rate
- Rework rate
- Human rejection rate
- Critical error rate

### Throughput

- Runs per period
- Completed content packages
- Cycle time

### Efficiency

- Cost per run
- Cost per content package
- Human review time

### Learning

- Test improvement rate
- Repeated failure categories
- Knowledge updates from feedback

## Metric Rules

Metric ต้องมี Definition, Source, Time Window และ Owner

ห้ามสร้างเป้าหมายตัวเลขโดยไม่มี Baseline และบริบท

ห้ามใช้ Metric เดียวเป็นตัวแทนคุณภาพทั้งระบบ
