# Experiment Design

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

## Required Fields

- Experiment ID
- Objective
- Baseline
- Hypothesis
- Independent variable
- Outcome metrics
- Context / audience
- Comparison method
- Duration / sample definition
- Confounders
- Decision rule
- Owner
- Start / end date

## Hypothesis Format

> หากเปลี่ยน **X** ภายใต้ **Context Y** เราคาดว่า **Outcome Z** จะเปลี่ยน เพราะ **Reason R**

## Good Experiment

ต้องทำให้เรารู้ว่า “อะไรเปลี่ยน” และ “ผลต่างจาก Baseline อย่างไร” ได้มากที่สุดภายใต้ข้อจำกัดจริง

## Do Not

- เปลี่ยนหลายตัวแปรโดยไม่บันทึก
- เปรียบเทียบ Context ต่างกันราวกับเป็นการทดลองเดียวกัน
- เลือกเฉพาะผลที่ชอบ
- เปลี่ยนระบบจากข้อมูลเล็กน้อยแล้วประกาศเป็นกฎถาวร
