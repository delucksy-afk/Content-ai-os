# Learning Loop

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1

```text
Production Output
      ↓
Performance / Quality Data
      ↓
Observation
      ↓
Pattern / Anomaly
      ↓
Hypothesis
      ↓
Experiment
      ↓
Result
      ↓
Insight
      ↓
Decision
      ↓
Knowledge / Prompt / Workflow Update
      ↓
Versioned Release
      ↓
New Production Output
```

## Learning Types

### Content Learning
อะไรทำให้ Content เหมาะกับ Audience / Intent

### Packaging Learning
ความสัมพันธ์ของ Title / Thumbnail / Content

### Workflow Learning
ขั้นตอนไหนสร้าง Delay / Error / Rework

### Automation Learning
Dependency หรือ Failure แบบใดเกิดซ้ำ

### Knowledge Learning
ข้อมูลใดควรเพิ่ม แก้ หรือ Deprecate

## Feedback Rule

Performance data เป็น Evidence สำหรับการตั้งคำถาม ไม่ใช่คำตอบอัตโนมัติว่าเหตุเกิดจากองค์ประกอบใด
