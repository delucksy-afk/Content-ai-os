# Language Guide — แนวทางการใช้ภาษา

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1  
**วันที่ปรับปรุงล่าสุด:** 2026-08-17

---

## 1. Primary Language

ภาษาไทยเป็นภาษาหลักของ Content AI OS สำหรับ Constitution, Policies, Rules, Decision Framework, Documentation, คำอธิบายระบบ และข้อกำหนดที่มีผลต่อการตัดสินใจ

## 2. Source of Truth

สำหรับเอกสารที่มีทั้งภาษาไทยและภาษาอังกฤษ:

> **ภาษาไทยถือเป็น Source of Truth**

ภาษาอังกฤษใช้เพื่อ Technical Terminology การค้นหา การเชื่อมต่อกับ Software และ Documentation ภายนอก หากสองภาษาขัดกัน ให้ยึดภาษาไทยจนกว่าจะมีการแก้ไขอย่างเป็นทางการ

## 3. Technical Terms

สามารถใช้ Technical Terms ภาษาอังกฤษในวงเล็บหรือร่วมกับภาษาไทยเมื่อช่วยรักษาความหมายมาตรฐาน เช่น Research, Knowledge, Workflow, Prompt, Automation, Evidence, Citation, Quality Standard และ Human Review

## 4. Clarity

ภาษาของระบบต้องชัดเจน ตรงไปตรงมา ไม่กำกวม ไม่ใช้ศัพท์ซับซ้อนโดยไม่จำเป็น และแยก Fact ออกจาก Opinion พร้อมระบุความไม่แน่นอนเมื่อมี

## 5. Avoid False Certainty

หลีกเลี่ยงคำที่สร้างความมั่นใจเกินหลักฐาน เช่น แน่นอน รับประกัน ได้ผลเสมอ ไม่มีข้อผิดพลาด หรือดีที่สุด เว้นแต่มีหลักฐานรองรับเพียงพอ

## 6. Terminology Consistency

คำสำคัญของระบบต้องใช้ความหมายคงที่ตาม `DEFINITIONS.md`

## 7. Version and Change

หากเปลี่ยนความหมายของคำสำคัญ ต้องระบุคำเดิม คำใหม่ เหตุผล เอกสารที่ได้รับผลกระทบ และบันทึกใน CHANGELOG
