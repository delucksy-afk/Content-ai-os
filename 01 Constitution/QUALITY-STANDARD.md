# Quality Standard — มาตรฐานคุณภาพ

**สถานะ:** ACTIVE  
**เวอร์ชัน:** v0.1  
**วันที่ปรับปรุงล่าสุด:** 2026-08-17

---

## 1. Purpose

กำหนดมาตรฐานขั้นต่ำสำหรับการประเมินคุณภาพของ Research, Knowledge, Strategy, Prompt, Script, Content และ Output ที่สร้างโดย Content AI OS

## 2. Accuracy

ข้อมูลต้องถูกต้องตาม Evidence ที่มี ไม่บิดเบือนบริบท ไม่สร้างข้อเท็จจริงขึ้นเอง และไม่กล่าวเกินหลักฐาน

## 3. Relevance

Output ต้องตอบวัตถุประสงค์ของงาน ข้อมูลที่ถูกต้องแต่ไม่เกี่ยวข้องกับเป้าหมายไม่ถือว่าเป็น Output คุณภาพสูง

## 4. Clarity

Content ต้องเข้าใจง่าย มีโครงสร้าง ไม่กำกวม ไม่ใช้คำฟุ่มเฟือยโดยไม่จำเป็น และเหมาะกับกลุ่มเป้าหมาย

## 5. Usefulness

Output ควรสร้างประโยชน์ที่ชัดเจนต่อผู้ใช้หรือเป้าหมายของระบบ

## 6. Evidence Quality

ข้อกล่าวอ้างสำคัญต้องมี Evidence ที่เหมาะสม ยิ่งสำคัญหรือเสี่ยงสูงยิ่งต้องการ Evidence ที่มีคุณภาพสูงและการตรวจสอบที่เหมาะสม

## 7. Originality and Value

Content ไม่ควรเป็นเพียงการเรียบเรียงใหม่โดยไม่มีคุณค่าเพิ่มเติม ควรมี Insight, Explanation, Synthesis, Perspective, Practical Value หรือ New Connection ตามความเหมาะสม

## 8. Consistency

Output ต้องสอดคล้องกับ Mission, Vision, Core Principles, Evidence Policy, Ethics Policy และ Language Guide หากขัดกับ Constitution ต้องตรวจสอบก่อนใช้

## 9. Human Review

ระดับการตรวจสอบต้องเหมาะกับความเสี่ยง ความสำคัญ ความซับซ้อน และผลกระทบ

## 10. Quality Gate

```text
[ ] ถูกต้องหรือไม่?
[ ] มี Evidence รองรับหรือไม่?
[ ] Citation ถูกต้องหรือไม่?
[ ] ตรงกับเป้าหมายหรือไม่?
[ ] เข้าใจง่ายหรือไม่?
[ ] มีคุณค่าหรือไม่?
[ ] มีความเสี่ยงด้านจริยธรรมหรือไม่?
[ ] สอดคล้องกับ Constitution หรือไม่?
[ ] จำเป็นต้อง Human Review หรือไม่?
```

## 11. Quality Is Not Perfection

> **Output มีคุณภาพเพียงพอตามวัตถุประสงค์ ความเสี่ยง และบริบท และสามารถตรวจสอบและพัฒนาต่อได้**

## 12. Continuous Improvement

เมื่อพบข้อผิดพลาด ให้ตรวจว่าเกิดจาก Output หรือระบบที่สร้าง Output หากเกิดซ้ำควรปรับ Knowledge, Prompt, Workflow, Policy, Quality Gate หรือ Automation ตามสาเหตุ
