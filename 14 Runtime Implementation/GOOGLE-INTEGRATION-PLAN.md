# Google Integration Plan

**สถานะ:** PLANNED

## Google Drive

Use for large artifacts:

- research files
- generated assets
- reports
- media

Initial permission goal: minimum required access to a dedicated Content AI OS folder rather than the entire Drive.

## Google Sheets

Use for V1 operational registry / measurement support:

- run registry
- content registry
- experiment registry
- metric records
- cost records

Initial permission goal: access only to dedicated spreadsheets where practical.

## Safety

Do not grant full Drive access if folder-level or narrower access is sufficient. Do not store secrets in Sheets.

## First Integration

Prefer a dedicated test folder and test spreadsheet before production assets are connected.
